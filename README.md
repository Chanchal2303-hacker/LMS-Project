# SkillTracker – Learning Management System (LMS)

## 📌 Project Overview

SkillTracker is a web-based Learning Management System (LMS) designed to help students manage their learning activities through a simple and user-friendly dashboard.

The project provides different sections such as Dashboard, Courses, Assignments, and Profile to organize student information and academic activities in one place.

The main objective of this project is to create an organized platform where students can easily access their courses, track assignments, view their profile, and navigate between different sections.

## 🎯 Project Objectives

- To develop a simple and user-friendly LMS interface.
- To organize different academic sections in one platform.
- To provide easy navigation between Dashboard, Courses, Assignments, and Profile.
- To understand and implement HTML, CSS, and JavaScript.
- To practice teamwork and collaborative project development.

## 📄 Project Modules

### 1. Dashboard Module
- Displays the main dashboard interface.
- Provides a welcome section for students.
- Includes navigation options to access different modules.
- Uses JavaScript for dashboard-related functionality.
- Provides buttons to navigate to other pages.

### 2. Courses Module
- Provides a separate section for courses.
- Organizes course-related information.
- Allows students to access the courses section through navigation.

### 3. Assignments Module
- Provides a dedicated section for assignments.
- Organizes assignment-related information.
- Helps students access their academic tasks.

### 4. Profile Module
- Provides a separate student profile section.
- Displays student-related information.
- Organizes personal and academic details.

## 💻 JavaScript Functionality

JavaScript is used to add functionality to the dashboard.

Some implemented functionalities include:

- Navigation between different HTML pages.
- Button click event handling using `onclick`.
- Functions for handling dashboard actions.
- Updating dashboard-related content.

Example:

```javascript
function showCourses() {
    window.location.href = "courses.html";
}
```

This function redirects the user to the Courses page when the corresponding button is clicked.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all HTML, CSS, and JavaScript files are in their respective folders.
4. Open `index.html` in a web browser.
5. Navigate through the different LMS modules using the available navigation options.
